# 园园 (Yuanyuan) · 桌面小魔女

一个会陪你的 **Electron 桌面宠物**（虚拟桌宠）。透明无边框窗口、始终置顶，支持待机姿态、键鼠跟随、互动动作、生日/生理期提醒等。渲染基于原生 Canvas 帧动画引擎，不依赖任何游戏引擎或前端框架。

> 本项目是桌面应用，需在 **Windows + 桌面环境**下运行；纯服务端 / 无 GUI 环境无法预览。

---

## ✨ 功能特性

- **桌面宠物本体**：透明无边框、始终置顶、可拖拽、可甩飞、可拎起
- **待机姿态**：内置 15 种动画，设置里**可多选**，随机播放 + 定时轮播（只选一个则固定不随机）
- **行为模式**（右键菜单 / 托盘菜单一键切换）：
  - **跟随状态** —— 只跟随鼠标和键盘，不做其它动作
  - **待机状态** —— 按所选姿态随机播放
- **跟随**：
  - 鼠标跟随（视线跟着鼠标转）
  - 键盘跟随（检测到你敲键盘才播放打字动画，停手约 1.2 秒回到静止）
- **互动动作**：摸摸头、做个动作、骑扫帚飞起来、去散步、睡一会 / 叫醒、回到待机
- **提醒系统**：生日（阳历 / 阴历）、生理期，支持双历法；开机检查 + 每 30 秒定时检查；同一条不重复提醒
- **对话气泡 / 闲聊**
- **设置面板**：动作偏好、跟随模式、提醒、外观缩放、开机自启等
- **右键菜单 + 系统托盘菜单**

## 🧰 技术栈

| 层 | 技术 |
| --- | --- |
| 主进程 | Electron（`main.js` / `preload.js`） |
| 渲染进程 | 原生 Canvas 2D 帧动画引擎（无框架、无游戏引擎） |
| 状态机 | 自研 `behavior.js`：`IDLE / REACT / SLEEP / WAKE / WALK / DRAG / SPECIAL / FLY / THROW` |
| 素材清单 | `tools/scan_assets.py` 自动扫描 `Material/` 生成 `renderer/assets-manifest.js` |
| 打包 | `electron-builder`（NSIS 安装包） |

├── package.json
└── ../Material/             # 原始素材（2048² 透明 PNG，独立目录）

## 🚀 开发 / 运行

```bash
npm install      # 安装依赖（electron + electron-builder）
npm start        # 开发模式运行（在本机 Windows 桌面环境下）
```

> 修改或新增素材后，运行 `npm run scan` 重新生成素材清单。

## 📦 打包

```bash
npm run dist     # 生成 NSIS 安装包 → dist/园园 Setup 1.0.0.exe
```

说明：

- **图标**：安装包与已安装应用的图标均取自 `build/icon.ico`（256×256）。替换为你自己的图标即可。
- **代码签名**：当前未做签名（`win.sign: null`），安装时系统可能提示"未知发布者"，属正常现象；如需消除提示需自行配置代码签名证书。
- **素材路径**：`../Material` 作为 `extraResources` 打包进 `resources/Material`，运行时由 `preload.js` 自动定位，**装到任意机器都能正确找到素材**，不会白屏。
- **渲染策略**：角色动画帧为 2048×2048 透明 PNG（留白较多），渲染引擎按"内容包围盒"裁剪并留边显示，保证各状态下角色大小一致、且边缘不被裁切。

---

## 🗂 素材说明

- 角色动画帧为 **2048×2048 透明 PNG**，单帧人物只占画面一部分（大量留白）。渲染引擎会在运行时按非透明内容裁剪、统一缩放并留白，因此素材**不需要**预先抠成贴边尺寸。
- 透明素材（如跟随鼠标用的眼神帧）直接缩放使用，不会被二次抠背景。
- 修改 / 新增素材后运行 `npm run scan` 重新生成 `renderer/assets-manifest.js`。
